# sl8-templates

A collection of reusable templates for the [StartHalo](https://github.com/StartHalo) ecosystem.

## Overview

`sl8-templates` provides ready-to-use templates to help teams quickly scaffold new projects, services, and configurations following StartHalo best practices.

## Getting Started

### Prerequisites

- [Git](https://git-scm.com/)

### Usage

1. **Browse available templates** – explore the folders in this repository to find the template that fits your use case.

2. **Clone or copy a template** – clone the entire repository and copy the relevant template directory into your project:

   ```bash
   git clone https://github.com/StartHalo/sl8-templates.git
   cp -r sl8-templates/<template-name> my-new-project
   ```

3. **Customise** – follow the instructions in each template's own `README.md` to configure it for your needs.

## Repository Structure

```
sl8-templates/
├── README.md          # This file
└── <template-name>/   # Individual template directories
    └── README.md      # Template-specific documentation
```

## Contributing

Contributions are welcome! To add a new template or improve an existing one:

1. Fork this repository.
2. Create a new branch: `git checkout -b feat/my-template`.
3. Add your template in a clearly named subdirectory and include a `README.md` describing its purpose and usage.
4. Open a pull request with a description of what the template provides.

Please ensure your template follows the existing conventions and is well-documented.
